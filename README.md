# UrbanView3D-1.0
UrbanView3D 1.0 is a custom software for viewing 3D data comprising of:
- LiDAR data (available at clss.si)
- 3D city model in OBJ format (an example available at: https://doi.org/10.5281/zenodo.17036832)

To inspect the results of envrionmental simulations, the user can load the data in binary format, an example is available at https://doi.org/10.5281/zenodo.17640793.
